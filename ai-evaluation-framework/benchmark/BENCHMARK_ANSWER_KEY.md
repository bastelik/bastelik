# Benchmark Answer Key & Illustrative Adjudications

This answer key provides one defensible evaluation path. Scores are illustrative; evaluators should explain any reasonable difference by reference to the rubric and evidence.

## B-01 — Unsupported outcome inference

### Claim analysis

| Claim | Classification | Rationale |
|---|---|---|
| The pilot enrolled 180 participants. | Supported | Explicitly stated in the excerpt. |
| The pilot operated at three locations. | Supported | Explicitly stated in the excerpt. |
| The pilot improved employment prospects. | Not established | The excerpt says post-program employment data were not collected. |

### Illustrative scores

| Dimension | Score | Rationale |

| Evidence and source handling | 1 | The response turns an unmeasured outcome into an asserted result. |

## Calibration notes

1. **Accuracy and fluency are separate.** A fluent response can still be factually or semantically wrong.
2. **Not established is not the same as contradicted.** In B-01, the report does not prove that employment did not improve; it says the relevant data were not collected.
3. **Hard constraints are testable.** Exact counts and word limits should be checked directly, not judged impressionistically.
4. **Preserve modality.** Words expressing possibility, probability, obligation, and certainty materially affect meaning.
5. **Document the reason for a score.** A number without evidence is not a useful QA record.
